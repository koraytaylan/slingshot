- **Exceptions:** one recorded divergence and one plan defect fixed in its own commit. `inspect-open-service-gateway-initiative-configuration` implements the duplicate-property-key identity as Unicode lowercase mapping followed by normalization form C rather than the specified Unicode 15.1 default case folding followed by form C, because no full-case-folding table is available to this build and transcribing one from memory would be worse than saying so. The two agree on every ASCII, Latin, Greek, and Cyrillic spelling and differ where a full fold expands, so this identity separates two keys full folding would join: it accepts a pair the specification refuses as duplicates and never the reverse. A test pins the known divergence on `straße` and `strasse`. The redaction policy folds ASCII only, by specification, so which values are read does not depend on this. Two `fix(0901)` commits corrected the redeclared-bound scan the module scaffold owns: it compared every named constant in the command family against every limit value, so an HMAC tag width collided with `maximum_component_resource_type_segments` and a SHA-256 digest width with `maximum_property_predicates`, and it scanned whole lines including prose, so a failure message saying "the signed 64-bit range" counted as a second declaration. It now catches a redeclared bound by its name and looks only outside string literals. `fix(0902)` supplied the normalization capability, manifest edges, and probe that the repository path grammar's own instruction to require already-normalized input needs but its recorded footprint omitted.
