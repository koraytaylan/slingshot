- **Exceptions:** one recorded divergence and one plan defect fixed in its own commit. `inspect-open-service-gateway-initiative-configuration` implements the duplicate-property-key identity as Unicode lowercase mapping followed by normalization form C rather than the specified Unicode 15.1 default case folding followed by form C, because no full-case-folding table is available to this build and transcribing one from memory would be worse than saying so. The two agree on every ASCII, Latin, Greek, and Cyrillic spelling and differ where a full fold expands, so this identity separates two keys full folding would join: it accepts a pair the specification refuses as duplicates and never the reverse. A test pins the known divergence on `straße` and `strasse`. The redaction policy folds ASCII only, by specification, so which values are read does not depend on this. One further deviation is recorded rather than hidden: the architecture places the `Command` and `CommandResult` enums in `command/mod.rs`, and the repository's own structural rule says a family root declares its children and nothing else. The rule wins, because three hundred lines of enum in a file whose job is to list modules would be worse than moving them, so they live in `catalog.rs` beside the table that describes them. Three more plan defects were fixed in their own commits before the task that needed them: `fix(1102)` gave the shared anchor-containment rule one home in `query_paths` rather than six copies; `fix(1202)` split the package selection language into its own `package_selection` leaf, because the command file cannot hold both contracts under the thousand-line rule; and `fix(1302)` let the schema task write the schema module its own architecture names. `fix(0905)` corrected landed work rather than a footprint: `NotEquals` read an absent property as unequal, and the discovery architecture says every operator answers no to absence, which is also the reading that stops one misspelled property path from matching an entire repository. Two `fix(0901)` commits corrected the redeclared-bound scan the module scaffold owns: it compared every named constant in the command family against every limit value, so an HMAC tag width collided with `maximum_component_resource_type_segments` and a SHA-256 digest width with `maximum_property_predicates`, and it scanned whole lines including prose, so a failure message saying "the signed 64-bit range" counted as a second declaration. It now catches a redeclared bound by its name and looks only outside string literals. `fix(0902)` supplied the normalization capability, manifest edges, and probe that the repository path grammar's own instruction to require already-normalized input needs but its recorded footprint omitted.
