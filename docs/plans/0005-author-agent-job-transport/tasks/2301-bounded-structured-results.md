# Bounded Structured Results

Validate bounded logical results, enforce declared remote-artifact alternatives, sanitize classified configuration values, and externalize larger accepted inline results through one daemon-owned machine disposition.

**Steps:**

1. Commit logical inline; exact/missing/wrong CommandCanonicalJsonContractDigest, either schema-root annotation/role digest, unchanged-five-field SelectedCommandContractIdentity, or SubmittedCommandDigest on terminal results/failures including contract-only and limits-only mismatch; valid-shaped same-command/different-validated-arguments substitutions; exact expected load/package artifact echo including 262,144/262,145 load threshold, maximum lengths, suggested names, and the load result's requested path; all exact configuration lookup/getProperties-dictionary/two-phase-access/PID/unsupported/malformed/value/result-budget failures and nine-type/four-carrier/metatype-redaction conversion edges without a partial map; literal discovery-anchor/budget/continuation-token no-partial cases; exact load including `load_budget_exceeded`; package profile/filter/root/read/FileVault/staging/publication failures and publication-outcome-unknown plus eight-way evaluation budgets; create seven and add eight authoritative-no-effect failures including `parent_not_orderable`, plus mutation-outcome-unknown; exact replication preflight, zero/partial admission, and outcome-unknown cases; unknown/omitted/duplicate/changed identifier or slot; wrong command/media; machine/local-externalization/general-agent-inline/capacity boundaries; post-success result loss; noncanonical/unknown field; configuration metatype evidence/sensitivity; and failed fixtures before implementation.

6. Size both result dispositions for local/Model Context Protocol headroom; implement the architecture's total expanded registry-category mapping using shared RecoveryExecutionEvidence/TerminalFailureDisposition and no generic compensation field.
